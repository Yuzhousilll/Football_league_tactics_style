# 第3章 球队成绩竞争力评估报告

## 3.1 成绩指标选取

本章不再使用积分、排名、净胜球等联赛结果变量来构建竞争力指标，而是改用更贴近比赛过程本身的“场上动作变量”进行主成分分析。这样处理的核心考虑在于：如果直接将积分、排名等结果变量纳入模型，那么最终得到的综合指标很大程度上只是对联赛成绩的再表达，难以体现球队在比赛过程中通过具体动作所表现出来的真实竞争能力。相反，射门、助攻、拦截、造犯规等变量更接近球队在场上的行为输出，因此更适合作为“过程型竞争力”的度量基础。

结合现有数据表 `style_metrics_all.csv` 的字段结构，并在多组候选变量方案中对KMO、Bartlett检验、累计解释率和共同度进行比较后，本文最终选取以下8个动作变量作为第三章主成分分析的输入指标：

1. `shots_per_match`
2. `shots_on_target_per_match`
3. `assists_per_match`
4. `cross_volume_per_match`
5. `penalties_won_per_match`
6. `tackles_won_per_match`
7. `interceptions_per_match`
8. `fouls_drawn_per_match`

这8个变量可以分为三类。

第一类是进攻创造与终结尝试指标，包括 `shots_per_match`、`shots_on_target_per_match` 和 `assists_per_match`。它们分别反映球队的射门总量、有效射门质量以及转化为关键传递和进球机会的组织能力。

第二类是进攻推进和进攻路径指标，包括 `cross_volume_per_match` 和 `penalties_won_per_match`。其中传中次数反映边路推进和传中组织的使用强度，赢得点球则反映球队在禁区侵入和直接威胁制造方面的能力。

第三类是防守和对抗行为指标，包括 `tackles_won_per_match`、`interceptions_per_match` 和 `fouls_drawn_per_match`。其中前两项反映防守对抗和预判拦截能力，最后一项反映球队在身体对抗和持球推进过程中制造犯规、打断比赛节奏的能力。

需要强调的是，这一指标体系刻画的不是“最终联赛成绩”，而是球队在比赛层面的综合动作表现。因此，本章所构建的竞争力指数，更准确地说是一种“基于场上行为的竞争力代理指标”。它能够从比赛过程的角度，对球队的攻击性、组织性、对抗性和防守活动水平进行综合概括。

## 3.2 主成分分析：综合成绩竞争力指数构建

### 3.2.1 数据适配性检验

在正式提取主成分之前，首先对样本进行适配性检验。本研究共使用2016_2017至2024_2025赛季的180个球队-赛季样本。对上述8个动作变量进行标准化处理后，得到如下检验结果：

1. KMO = 0.7023
2. Bartlett球形检验：
   - $\chi^2 = 883.0321$
   - 自由度 = 28
   - $p < 0.001$

KMO值超过0.7，说明变量之间具有较好的共同因子结构；Bartlett检验显著拒绝相关矩阵为单位矩阵的原假设，说明变量间相关性足以支持降维分析。因此，从统计意义上看，这组动作变量适合进行主成分分析。

### 3.2.2 主成分个数与解释率

依据特征值大于1的Kaiser准则，最终保留3个主成分。各主成分解释率如下：

1. PC1：42.00%
2. PC2：19.00%
3. PC3：14.25%

累计解释率达到75.26%，说明这3个主成分已经能够较充分地概括原始8个动作变量的大部分信息。在社会科学和体育数据研究中，累计解释率超过70%通常可以认为具有较好的降维效果，因此这一结果是可以接受的。

与前一版“积分/排名导向”的PCA不同，这里保留下来的并不是一个单一结果主轴，而是三个彼此有区分度的比赛行为维度。这也说明，当竞争力被定义为“场上动作综合表现”时，其内部结构明显比结果变量更复杂、更具多维性。

### 3.2.3 主成分载荷解释

根据载荷矩阵结果，三个主成分可做如下解释。

#### PC1：进攻威胁维度

考察代表进攻火力的“进攻威胁”维度PC1，该主成分在 `shots_per_match`（0.937）、`shots_on_target_per_match`（0.954）以及 `assists_per_match`（0.918）上均呈现出极高的正向载荷，`penalties_won_per_match`（0.550）也做出了中等贡献，刻画了球队在进攻端的持续施压与转化能力。

#### PC2：边路推进与主动防守维度

“边路推进与主动防守”维度PC2将 `cross_volume_per_match`（0.623）、`tackles_won_per_match`（0.722）和 `interceptions_per_match`（0.748）整合在了一起，这表明该类球队的竞争力并不主要源于中路渗透或射门频次，而是依赖于两个边路的高频起球，以及防守破坏与提前拦截，反映出球队在攻防转换和空间争夺中的活跃度。

#### PC3：对抗制造与比赛碎片化维度

考察“对抗制造与比赛碎片化”维度PC3，`fouls_drawn_per_match`（0.893）占据主导，`tackles_won_per_match`（0.371）与 `penalties_won_per_match`（0.266）也起到一定作用，而 `cross_volume_per_match`（-0.363）呈现负相关。这意味着PC3反映的不是常规的套路化进攻，而是一种以突破和制造犯规为方式的“造杀伤”能力。PC3得分较高的球队擅长利用身体对抗与判罚尺度来制造碎片化定位球机会，通过将比赛切碎来制造场上优势，并遏制对方的持续组织和长时间球权控制。

### 3.2.4 综合竞争力指数构建方法

在本研究中，球队的综合竞争力指数由保留的3个主成分按解释方差比加权构成。由于三者的解释率分别为42.00%、19.00%和14.25%，因此PC1在综合指标中权重最高，PC2次之，PC3再次之。这种加权方式能够保证最终指标既突出主要信息，又保留比赛行为中的结构差异。

换言之，最终的 `competitiveness_index` 并不是单一进攻变量的替代，也不是某一个动作频次的直接排序，而是对球队场上行为模式进行降维后的综合分数。分值越高，说明球队在进攻创造、推进强度、防守介入和对抗制造等方面展现出更强的综合比赛能力。

### 3.2.5 主成分结果的统计特征

从共同度看，多数变量都得到了较好的解释：

1. `shots_per_match`：0.9165
2. `shots_on_target_per_match`：0.9339
3. `assists_per_match`：0.8458
4. `cross_volume_per_match`：0.6613
5. `penalties_won_per_match`：0.3738
6. `tackles_won_per_match`：0.7292
7. `interceptions_per_match`：0.7923
8. `fouls_drawn_per_match`：0.8015

其中，`penalties_won_per_match` 的共同度相对较低，说明该变量虽然具有一定解释意义，但与其他动作变量的协同性较弱。这并不意味着它无效，而是说明“赢得点球”更像一种低频但高价值事件，统计上不如射门、助攻、拦截这类高频动作稳定。

总体上看，本章所建立的动作变量PCA模型在统计上是可接受的，在理论上也更符合“由场上行为解释竞争力”的研究取向。

## 3.3 球队案例分析：曼彻斯特联

为了更具体地展示综合竞争力指数的解释作用，本文以曼彻斯特联为例，对其在2016_2017至2024_2025赛季期间的主成分变化和综合指数变化进行考察。

### 3.3.1 曼联的总体表现特征

从均值看，曼联在整个样本期内的各主成分平均水平分别为：

1. PC1 平均值：0.9782
2. PC2 平均值：0.0863
3. PC3 平均值：0.1115
4. 综合竞争力指数均值：0.5888

这一结果说明，曼联在样本期内最主要的特点并不是极强的边路推进和对抗制造，而是中等偏上的进攻创造能力，即PC1相对更稳定地维持在正值区间。相比之下，PC2和PC3更容易出现正负波动，表明球队在边路组织、防守介入和对抗制造方面的比赛风格并不稳定。

### 3.3.2 不同赛季的变化轨迹

从赛季表现看，曼联的动作型竞争力呈现明显波动。

1. 2016_2017赛季，曼联的综合竞争力指数为1.3212，在当赛季20队中位列第5，说明其整体动作表现仍处于联赛上游。该赛季PC2达到3.8289，远高于其余赛季，表明球队在边路推进、防守介入和比赛对抗方面表现得尤为突出。

2. 2018_2019至2020_2021赛季，曼联的PC1持续维持在较高水平，其中2019_2020赛季综合指数达到1.1834，赛季内排名第4。这表明球队在射门、射正和助攻等进攻创造动作上仍具备较强活跃性。

3. 2021_2022赛季以后，曼联的综合指数明显回落。2021_2022赛季指数几乎降至0（-0.0011），2023_2024赛季进一步降至0.2582，2024_2025赛季仅为0.0971，并在赛季内排名下滑至第12。这说明球队在关键动作层面的综合输出已明显弱于样本期前段。

4. 从结构上看，后期曼联的PC2与PC3多次转为负值，反映球队在边路推进、防守介入或对抗制造方面缺乏稳定优势。也就是说，曼联在部分赛季仍然能够维持一定的进攻创造水平，但未必能够在更全面的比赛行为维度上保持竞争力。

### 3.3.3 曼联案例的启示

曼联案例表明，球队的竞争力并不必然等于单一结果好坏，而是体现为多类动作变量之间的综合平衡。对曼联而言，最具代表性的特征是：

1. 其竞争力起伏较大，说明比赛行为结构的稳定性不足。
2. 某些赛季的高分主要来自PC1或PC2的阶段性抬升，而不是三个维度同步增强。
3. 当进攻创造、边路推进和对抗制造不能形成协同时，综合竞争力指数就会显著下降。

因此，曼联的例子说明，本章建立的动作型竞争力指数不仅能够描述“球队是否强”，还能够解释“球队强在什么动作维度”以及“为何会在不同赛季出现明显波动”。

## 3.5 本章小结

本章基于比赛动作变量而非积分、排名等结果变量，重构了球队成绩竞争力评估框架。通过对射门、射正、助攻、传中、造点、铲球、拦截和造犯规等8项动作指标进行主成分分析，最终提取出3个具有明确含义的主成分，累计解释率达到75.26%。结果表明，球队的竞争力并不是单一维度，而是由进攻创造、推进与防守介入、对抗制造等多个行为层面共同构成。

这一处理方式避免了将联赛结果变量直接作为输入所带来的“结果重复表达”问题，使得第三章的竞争力指标更贴近球队在比赛中的真实行为表现，也为后续球员角色分析提供了更自然的桥梁。
