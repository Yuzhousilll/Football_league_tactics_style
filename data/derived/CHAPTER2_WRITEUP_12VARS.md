# 第2章结果写作稿（12变量正式版）

## 2.2 因子分析结果与解释

本文在2016-2017至2024-2025赛季英超球队数据基础上，选取12个风格指标进行因子分析。通过标准化处理后，依据特征值大于1的准则提取出3个公共因子。模型的累计解释能力约为70.94%，说明该因子结构能够较好地压缩原始变量信息，并保留主要风格差异。

从因子载荷结果看（见`data/derived/team_factor_loadings_12vars_2016_2025.csv`），三个因子的含义可解释为：

1. 因子1（综合竞争质量因子）
该因子在`goals_per_match`（0.996）、`shots_on_target_per_match`（0.917）和`goals_per_sot`（0.725）上呈现较高正载荷，同时在`goals_against_per_match`（-0.669）和`shots_on_target_against_per_match`（-0.674）上呈现较高负载荷。说明因子1高分球队通常进攻产出更高、防守承压更低，体现“攻防综合质量更优”的特征。

2. 因子2（进攻效率与执行风格因子）
该因子对`goals_per_sot`（-0.670）和`shots_on_target_per_match`（0.371）有较明显载荷，反映球队在进攻转化效率与进攻执行方式上的差异。该因子可理解为“机会转化与进攻执行偏好”的补充维度。

3. 因子3（防守风险与阵容波动因子）
该因子在`goals_against_per_match`（0.674）、`shots_on_target_against_per_match`（0.517）与`players_used`（0.553）上负荷较高，在`clean_sheet_pct`（-0.598）上呈负载荷，表明其刻画的是“防守失球风险+阵容使用波动”的联合特征。

整体上，因子1负责区分强弱格局，因子2和因子3进一步刻画球队在风格执行与防守风险上的结构差异。碎石图见`data/derived/scree_plot_12vars.png`，载荷热力图见`data/derived/factor_loadings_heatmap_12vars.png`。

## 2.3 基于因子得分的球队聚类识别

在3个因子得分基础上，采用K-means方法进行4类聚类，得到180个球队-赛季样本的分组结果（见`data/derived/team_clusters_assigned_12vars.csv`）。四类样本规模分别为40、40、54、46，分布较为均衡，这意味着分类结果不是由“极少数异常样本”支撑，而是对联赛整体样本都有覆盖。

从论文写作角度，可以把这一结果理解为：英超球队并不是简单地排成“强—弱”一条线，而是至少存在四种可识别、可复现、可比较的风格状态。

### 2.3.1 四类风格的直白解释（聚类结果）

各聚类中心（见`data/derived/team_cluster_statistics_12vars.csv`）可归纳为：

1. Cluster 1（高竞争质量型，n=40）
因子1显著为正（1.372），且因子2也为正（0.446），因子3接近0。这类球队最直观的特征是：
- 进攻端有稳定产出，不靠偶发进球；
- 防守端失球风险可控，不容易被持续压制；
- 比赛过程和结果通常都更“可预期”。
因此，它可以被理解为“强队常态型”或“高位竞争型”，常见于争冠/欧战区样本。

2. Cluster 0（执行型但上限受限，n=40）
因子2显著为正（0.908），但因子1为负（-0.745），因子3为负（-0.672）。这说明这类球队往往“有打法”，但“硬实力不够顶”。更直白地说：
- 战术特征比较鲜明，执行纪律不差；
- 但攻防综合质量不够高，难以长期稳定冲击更高排名；
- 其赛季表现容易停留在“有亮点但天花板明显”的区间。

3. Cluster 2（高风险波动型，n=54）
因子3显著为正（1.081），而因子1与因子2均略低于0，是样本最多的一类。其核心特征是：
- 防守端风险暴露偏高，比赛起伏大；
- 阵容和状态波动更明显，稳定性不足；
- 同一球队可能在短期内出现“能赢强队也会输弱队”的表现。
这类样本在中下游或转型期球队中更常见。

4. Cluster 3（低效率保守型，n=46）
因子2显著为负（-0.997），因子1和因子3也低于0。可直观理解为：
- 进攻端效率偏低，创造与转化都不占优；
- 整体策略更偏保守，比赛节奏与主动性不足；
- 更容易陷入“场面不差但拿分效率低”的状态。

二维散点可视化见`data/derived/cluster_scatter_f1_f2_12vars.png`与`data/derived/cluster_scatter_f1_f3_12vars.png`，聚类中心热图见`data/derived/cluster_centers_heatmap_12vars.png`，规模分布图见`data/derived/cluster_distribution_12vars.png`。

### 2.3.2 这些聚类结果到底“有什么意义”

为避免“只分了类但不知道能做什么”，建议在正文把意义写得更明确：

1. **把抽象数据变成可讨论的球队类型**
因子分析给出的是统计维度，聚类进一步把维度组合成“类型”。这使得后文可以直接讨论“某队属于哪一类、为何转类、转类后成绩如何”，而不是停留在抽象因子数值。

2. **把“强弱差异”拆解成“路径差异”**
同样是中游球队，有的属于执行型（Cluster 0），有的属于高风险型（Cluster 2），还有的属于低效率保守型（Cluster 3）。这说明成绩接近并不代表问题相同：有的短板在效率，有的短板在稳定性，有的短板在综合质量。

3. **为纵向分析提供“状态变量”**
聚类标签可以按赛季追踪，形成“风格轨迹”。这样就能研究：某队从Cluster 3到Cluster 1是如何发生的、持续多久、是否对应积分改善，从而把静态描述升级为动态解释。

4. **为下一章做可检验假设铺垫**
例如可直接提出：
- 长期处于Cluster 1的球队，是否平均积分更高、波动更小？
- 频繁在Cluster 0/2之间切换的球队，是否排名波动更大？
- 从Cluster 3跃迁到Cluster 0，是否先改善过程数据再改善结果数据？
这些问题都可以被数据检验，能显著增强论文“结论可验证性”。

5. **提升管理解释价值**
聚类结果可转化为更直观的决策语言：
- 如果球队属于Cluster 2，优先任务可能是降低防守风险与阵容波动；
- 如果球队属于Cluster 3，优先任务可能是提升进攻效率与转换质量；
- 如果球队属于Cluster 0，重点是突破综合质量上限而非仅维持执行纪律。
这使研究结论不仅可用于学术解释，也可服务于俱乐部实务讨论。

## 2.4 风格结构的时间演变
本节建议采用“联赛均值趋势—结构占比迁移—头部样本轨迹—机制归纳”的四层写法，以增强结果阐释深度和篇幅。除`top_teams_cluster_evolution_12vars.png`外，可同步引用`style_evolution_trends_12vars.csv`、`style_evolution_cluster_shares_12vars.csv`、`style_evolution_league_trends_12vars.png`与`style_evolution_cluster_shares_12vars.png`形成证据链。

### 2.4.1 联赛层面：三因子均值趋势的非对称变化

根据`style_evolution_trends_12vars.csv`，2016-2024年三因子并非同向演化，而是呈现显著“非对称变化”：

1. **Factor3（防守风险与阵容波动）上升最快**：年斜率+0.1264，累计增幅+0.4240（-0.0703→0.3537）。这说明联赛样本整体在防守端承压与阵容波动维度上明显抬升。
2. **Factor1（综合竞争质量）温和上升**：年斜率+0.0388，累计+0.1226（-0.0325→0.0901）。表明平均竞争质量存在改善，但改善幅度较为有限。
3. **Factor2（机会转化与执行倾向）总体回落**：年斜率-0.0204，累计-0.3425（0.3080→-0.0345）。反映联赛平均层面的进攻转化效率/执行倾向在样本期末低于样本期初。

这一结果可扩写为：英超风格演变并非“单向升级”，而是“质量温和提升与风险显著抬升并行”，同时伴随执行效率均值回落。换言之，联赛强度提高并不自动带来更低波动，反而可能推动球队在高压环境下承担更高的防守风险。

### 2.4.2 结构层面：聚类占比的阶段性迁移

由`style_evolution_cluster_shares_12vars.csv`可见，四类风格占比变化具有明显阶段特征，可按三个阶段叙述：

1. **2016-2020（中间与保守类型占优）**：Cluster 1和Cluster 4在多数赛季维持较高占比，显示联赛仍有大量“执行型但上限受限”与“低效率保守型”样本。
2. **2021-2022（风险型扩张阶段）**：Cluster 3占比从2020年的10%迅速抬升至2021年的40%，反映高风险波动风格开始系统性扩散。
3. **2023-2024（高波动冲高后回调）**：Cluster 3在2023年达到80%的峰值，2024年回落至45%，但仍显著高于早期水平，说明联赛结构虽有修复，但风险主导特征未完全消退。

若从全样本期首尾对比，Cluster 3占比提升20个百分点（25%→45%），Cluster 1下降10个百分点（25%→15%）。该结果可支撑“联赛风格由中间状态向两端分化”的论断，即部分球队向高竞争质量型靠拢，另有相当数量样本向高风险波动型集中。

### 2.4.3 球队层面：头部球队轨迹的稳定性异质

结合`top_teams_cluster_evolution_12vars.png`与聚类结果表，可将“传统强队”进一步拆解为两类轨迹：

1. **高稳定组（Liverpool、Manchester City）**：9个赛季均停留在高竞争质量类型（Cluster 2），几乎无风格漂移，体现出较强的体系连续性与策略一致性。
2. **高切换组（Chelsea、Manchester Utd）**：在不同赛季间频繁跨类（均出现7次类型切换），说明其在战术路径、阵容结构与风险暴露之间经历更高频重配。
3. **中等切换组（Arsenal、Tottenham Hotspur）**：切换次数约为3次，呈“阶段稳定+阶段调整”并存的中间状态。

这一异质性提示：头部球队优势不只由“某一赛季强度”决定，更受“风格状态可复制性”影响。长期稳定停留在高质量类型的球队，往往在赛季间表现波动更小，战略摩擦成本更低。

### 2.4.4 可直接加入正文的机制化讨论

为提升学术表达密度，建议在2.4末尾补入机制化过渡段：

“综合因子趋势、聚类占比与头部轨迹可知，英超在样本期内呈现‘质量改善慢、风险上升快、结构分化增强’的演化特征。该特征意味着，球队竞争力差异正在从传统的资源/能力差距，部分转向风险管理能力与阵容稳定性的差距。基于此，下一章可进一步检验：\(1\) 长期停留在高竞争质量类型是否显著提升积分上限；\(2\) 风格切换频率是否与成绩波动呈正相关；\(3\) 防守风险因子上升是否会削弱进攻效率改进带来的边际收益。”

使用上述写法后，2.4节不仅能“描述图表结果”，还能自然过渡到可检验命题，显著提升章节字数与论证完整度。
