# 第2章 英超球队风格识别与演变分析（12变量正式版）

## 2.1 研究设计与变量体系

本章目标在于构建一个可解释、可量化且可用于跨赛季比较的球队风格识别框架。基于`style_metrics_all.csv`中2016-2017至2024-2025赛季（共9个赛季）英超球队样本，形成180个“球队-赛季”观测。为平衡信息完整性与变量冗余，本文在前期全维度筛选基础上，最终保留12个风格变量进入正式模型：

1. `shots_on_target_per_match`
2. `goals_per_match`
3. `goals_per_sot`
4. `cross_share_of_touches`
5. `penalties_won_per_match`
6. `offsides_to_shots_ratio`
7. `goals_against_per_match`
8. `clean_sheet_pct`
9. `tackles_won_per_match`
10. `interceptions_per_match`
11. `shots_on_target_against_per_match`
12. `players_used`

上述指标覆盖进攻产出、进攻效率、进攻路径、防守承压、防守结果与阵容使用等关键维度。方法上，先对变量进行标准化，再通过因子分析提取潜在风格维度，随后以因子得分作为输入执行K-means聚类，以识别球队风格类型。最后通过赛季序列分析考察风格结构的动态演化。

## 2.2 因子分析结果

### 2.2.1 因子提取与解释度

基于12变量的标准化数据，按特征值大于1（Kaiser准则）自动提取3个公共因子。结果显示，三因子累计解释度约为70.94%，说明该结构能够在较少维度下保留多数原始信息。相较于直接使用高维指标进行聚类，因子压缩能够减弱多重共线性影响，并提升后续分类解释的一致性。

对应结果文件如下：
- 因子载荷：`data/derived/team_factor_loadings_12vars_2016_2025.csv`
- 因子得分：`data/derived/team_factor_scores_12vars_2016_2025.csv`
- 碎石图：`data/derived/scree_plot_12vars.png`
- 载荷热力图：`data/derived/factor_loadings_heatmap_12vars.png`

### 2.2.2 因子载荷结构与风格含义

根据载荷矩阵，三个因子的含义可概括如下。

1. Factor1：综合竞争质量因子
该因子在`goals_per_match`（0.996）、`shots_on_target_per_match`（0.917）和`goals_per_sot`（0.725）上呈高正载荷，同时在`goals_against_per_match`（-0.669）与`shots_on_target_against_per_match`（-0.674）上呈显著负载荷。其统计含义是：当球队在进攻端更具持续产出能力且防守端失球风险更低时，Factor1得分更高。因此，Factor1可视作表征“攻防综合质量”的主轴。

2. Factor2：机会转化与执行倾向因子
Factor2对`goals_per_sot`与部分进攻执行变量呈较高负载或中等载荷，反映同等进攻活动下的终结效率差异与执行路径差异。该因子更偏向“质量”而非“数量”，用于区分在机会管理、射门转化与组织偏好上存在系统差异的球队。

3. Factor3：防守风险与阵容波动因子
Factor3在`goals_against_per_match`（0.674）、`shots_on_target_against_per_match`（0.517）和`players_used`（0.553）上为正，在`clean_sheet_pct`（-0.598）上为负，说明其能够刻画“防守失稳与阵容变动”共同出现的风险结构。当球队防守端承压偏高、零封率偏低且阵容轮换幅度较大时，Factor3通常上升。

综合而言，Factor1提供“强弱主轴”，Factor2与Factor3提供“执行差异”和“风险差异”两个侧向补充维度。三者共同形成球队风格的多维表示，便于后续聚类识别与时序比较。

### 2.2.3 结果解释的边界

需要强调，因子命名属于“统计载荷基础上的实证解释”，而非先验定义。即，因子含义来自变量在样本中的共同变化模式，因此其解释应理解为“倾向性结构”而非单一因果机制。此外，个别变量共同度较低（如`tackles_won_per_match`、`interceptions_per_match`）提示其在当前因子结构中的解释贡献相对有限，这为后续稳健性检验（如旋转方案比较、样本分段检验）提供了进一步空间。

### 2.3.2 四类风格画像（更直白解释）

根据聚类中心值，四类风格可解释如下。

1. Cluster 2（高竞争质量型，n=40）
中心特征为Factor1显著为正（1.372），Factor2中度为正（0.446），Factor3接近0略负。可直白理解为：
- 进攻端有持续输出，不依赖偶然事件；
- 防守端风险可控，不容易长期被压制；
- 赛季表现通常更稳定，目标区间更靠前。
因此，该类更接近“强队常态样本”或“高位竞争群体”。

2. Cluster 1（执行偏强但综合质量受限型，n=40）
因子2明显为正（0.908），但Factor1显著为负（-0.745），Factor3亦为负（-0.672）。这类样本的核心是“有打法，但上限有限”：
- 执行层面特征鲜明，战术识别度较高；
- 但攻防综合质量不足，难以长期维持高位积分；
- 更常见于“体系较完整但硬实力未达顶级”的球队赛季。

3. Cluster 3（风险暴露与波动型，n=54）
Factor3显著为正（1.081），Factor1与Factor2略负，是样本中数量最多的一类。其典型表现为：
- 防守风险暴露偏高，比赛起伏较大；
- 阵容稳定性与比赛稳定性相互牵连；
- 容易出现“阶段性抢分—阶段性失速”交替。
该类常对应中下游球队或转型期球队。

4. Cluster 4（低效率保守型，n=46）
Factor2显著为负（-0.997），Factor1与Factor3均为负值。可理解为：
- 进攻端效率偏低，创造与终结都不占优；
- 整体策略偏保守，主动性不足；
- 更容易陷入“场面不失控、结果却拿分有限”的状态。

### 2.3.3 聚类结果的研究意义（写得更明确）

上述分群结果的价值，不仅是“把球队分成四类”，更在于把后续研究问题变得可检验、可解释：

1. 从“抽象因子”到“可讨论类型”
因子得分本身较抽象，而聚类标签能直接用于叙述：某队属于哪类、何时换类、换类后成绩是否改善。这样正文可以减少术语堆叠，提升可读性。

2. 从“强弱比较”到“路径比较”
同为中游球队，可能分别处在Cluster 1、Cluster 3或Cluster 4。它们成绩接近，但问题并不相同：有的是综合质量不足，有的是风险控制不足，有的是效率不足。该区分能避免“同分同治”的过度简化。

3. 从“静态横截面”到“动态轨迹”
聚类标签可按赛季追踪，形成风格迁移路径。由此可研究“短期跃迁”与“长期稳定”哪一种更有利于绩效提升，为下一章提供清晰的因果讨论入口。

4. 从“统计结果”到“管理语言”
四类风格可直接转为决策含义：
- Cluster 3优先解决防守风险与阵容波动；
- Cluster 4优先解决进攻效率与转化质量；
- Cluster 1需要突破综合质量上限而不只是维持执行；
- Cluster 2的关键是保持稳定并防止风险反弹。
这使本章结论不仅可用于学术解释，也可用于俱乐部层面的策略沟通。

## 2.4 风格演变分析（整合版）

本节在前述聚类和因子结果基础上，从“因子均值趋势”“聚类占比结构”和“头部球队轨迹”三个层面分析2016-2024的风格演进。

### 2.4.1 联赛层面因子趋势

这里“年斜率（slope_per_year）”的含义是：在样本期内，某个因子的联赛平均值每跨1个赛季平均变化多少。计算上可理解为将“赛季年份”与“因子联赛均值”做线性拟合后得到的斜率。斜率为正表示该因子总体上升，斜率为负表示总体下降；绝对值越大，变化速度越快。

基于`style_evolution_trends_12vars.csv`，联赛平均因子随时间变化呈现如下特征：

1. Factor3上升最明显（年斜率 +0.1264，2016-2024累计 +0.4240）。
这表明样本整体在“防守风险-阵容波动”维度上有增强趋势，反映联赛中部和下部样本在防守稳定性与人员连续性方面面临更大压力。

2. Factor2总体下降（年斜率 -0.0204，累计 -0.3425）。
说明机会转化与执行倾向因子在联赛平均水平上出现回落，可能与联赛竞争强度提升、防守对抗升级以及战术同质化有关。

3. Factor1小幅上升（年斜率 +0.0388，累计 +0.1226）。
体现整体竞争质量并未下降，且存在有限改善，但其增幅显著小于Factor3，提示“质量提升”与“风险抬升”并行。

对应图表：`data/derived/style_evolution_league_trends_12vars.png`。

#### 个案回到现实：以诺丁汉森林（2022-2025）为例

从理论数据回到现实足球世界，诺丁汉森林是一个很有代表性的样本。作为英格兰传统俱乐部，球队在2022年夏天升级回到英超，2022-2023赛季完成保级后，管理层判断原有阵容与比赛方式难以支撑长期英超生存，于是在2023与2024两个夏窗连续进行高强度重组。按公开转会汇总口径，球队在2023年夏窗约发生30人次流动（10入、20出）；2024年按一线队确认名单口径约发生40人次变动（11入、29出）。这种连续“大换血”与本章Factor3所刻画的“防守风险—阵容波动”维度具有较强现实对应关系。

若将该队2022-2025三个赛季因子得分与联赛均值趋势对照，可看到“重组—波动—再平衡”的典型路径：2022-2023赛季，Forest的Factor1=-0.933、Factor2=-1.066、Factor3=0.123，表现为综合质量与效率偏弱且已出现一定风险暴露；2023-2024赛季，Factor1回升至-0.303、Factor2回升至-0.819，但Factor3进一步升至0.893，说明球队在提升竞争质量的同时承受了更高的不稳定性成本；2024-2025赛季，Factor1转正至0.249、Factor2继续修复至-0.462，同时Factor3降至-0.686，显示在持续换血后，球队开始从“高波动过渡态”走向“风险回落后的结构再稳定”。

因此，这一个案与联赛层面的结论可以形成互证：联赛均值上Factor3抬升并不意味着所有球队都永久高风险，而更可能反映部分球队在重建期集中承压。紧接着可在下表加入Forest 2022-2025年三因子得分，作为“联赛趋势—球队机制”之间的桥接证据。


### 2.4.2 聚类结构占比演化

依据`style_evolution_cluster_shares_12vars.csv`，聚类占比在2016-2024的变化呈现结构性迁移：

1. Cluster 3占比上升最多（+20.00%）。
即"风险暴露与波动型"样本在后期赛季比重增加，说明联赛中存在更强的风格分化与不稳定性累积。

2. Cluster 1占比下降最多（-10.00%）。
执行偏强但综合质量受限的中间状态样本减少，可能意味着球队在竞争压力下向“高质量型”或“高风险型”两端分化。

3. 其余类别呈阶段性波动。
不同赛季中，部分聚类占比出现短期抬升后回落，说明风格演化并非单调过程，而受到教练更替、转会策略、赛程密度和伤病冲击等因素共同影响。

对应图表：`data/derived/style_evolution_cluster_shares_12vars.png`。

### 2.4.3 头部球队的风格轨迹

对传统六强样本进行因子轨迹可视化（`data/derived/style_evolution_top6_12vars.png`）后可见：

1. 头部球队总体更靠近高竞争质量区间，但在不同赛季仍存在因子波动，表明即便强队也会受到战术调整与人员更替影响。
2. 个别赛季中，强队在Factor3方向短暂抬升，反映高压赛程或阵容不稳定会对防守风险维度造成可观扰动。
3. 强队长期维持高位表现的核心并非单一进攻强度，而是攻防质量、效率与风险控制的协同。

### 2.4.4 综合判断与研究启示

将三类证据合并后可以得到一个更稳健的结论：

1. 英超球队风格演变表现为“整体质量温和提升”与“风险维度显著抬升”并行。
2. 联赛结构出现由中间形态向两端分化的迹象，高竞争质量与高风险波动两类在不同阶段交替扩张。
3. 风格迁移具有显著动态性，球队并非固定属于某一类，而是随管理策略与赛季环境在类别间转移。

这意味着后续章节若讨论“风格与成绩”的关系，不应仅采用静态横截面，而应采用“风格状态 + 演变方向”的联合解释框架。

### 2.4.5 可扩写的结果阐释路径（用于提升篇幅与深度）

为避免2.4节停留在“描述性罗列”，可按“现象—机制—影响—可检验命题”的四句式扩写每一小节。下面给出可直接落稿的扩写方向。

1. 因子趋势的“强弱对比”写法
可将三个因子放在同一比较框架中强调“非对称变化”：2016-2024期间，Factor3累计增幅（+0.4240）明显高于Factor1（+0.1226）的温和上升，而Factor2则出现累计回落（-0.3425）。这一“风险上升快于质量改善、执行效率均值回落”的组合，意味着联赛风格演化不是线性进步，而更接近“高强度竞争下的结构再平衡”。

2. 聚类占比的“阶段划分”写法
可把2016-2024拆分为三个阶段：
- 第一阶段（2016-2020）：Cluster 4与Cluster 1占比较高，联赛中存在较多“低效率保守型”与“执行偏强但综合质量受限型”样本；
- 第二阶段（2021-2022）：Cluster 3显著抬升（2021年达40%），显示风险暴露型风格开始扩散；
- 第三阶段（2023-2024）：Cluster 3在2023年冲高至80%，2024年虽回落至45%但仍高于早期均值，说明高波动结构并未完全逆转。
通过阶段化叙述，文本可以更自然地承接外部背景变量（赛程密度、财政约束、教练更替）并提升论证层次。

3. 头部球队的“稳定性异质”写法
可进一步突出“同属强队但稳定性不同”的发现：Liverpool与Manchester City在9个赛季中始终处于Cluster 2，表现出强风格连续性；Chelsea与Manchester Utd则分别出现7次类型切换，说明其风格调整更频繁、路径依赖更弱。该对比可作为“组织稳定性—风格稳定性—绩效稳定性”链条的经验依据，为下一章建立机制假说。

4. 由统计结果过渡到研究问题的写法
在每个小节末增加“因此，本研究在下一步将……”句式，例如：
“因此，下一章将检验Cluster 2的长期停留是否显著提升积分上限，并比较‘短期跃迁到Cluster 2’与‘长期稳定于Cluster 2’在绩效上的差异。”
这样可把描述性结果转化为可检验问题，增强章节之间的逻辑闭环。

### 2.4.6 可直接补入正文的示例段落（示范）

示例段落A（放在2.4.1末尾）：
“从联赛整体看，三因子并未呈现同向变化，而是出现明显分化：Factor1仅温和抬升，Factor3却持续走强，Factor2同步回落。这一结构说明，英超在样本期内并非简单朝着‘更强进攻+更稳防守’单一方向演进，而是在高对抗与高节奏环境中形成了‘质量小幅改善、风险显著抬升、执行效率承压’的复合特征。换言之，联赛平均水平的竞争质量提升，可能是以更高的波动性与更高的防守风险暴露为代价实现的。”

示例段落B（放在2.4.2末尾）：
“聚类占比的时序变化进一步支持上述判断。早期赛季中，中间类型（Cluster 1）与保守类型（Cluster 4）仍占据较大比重；而在后期，风险暴露型（Cluster 3）快速扩张并在个别赛季达到主导地位。这意味着联赛风格结构正在从‘中间集中’转向‘高风险扩散’，球队间差异不再主要表现为能力高低，而更多表现为风险承受方式与资源配置策略的差异。”

示例段落C（放在2.4.3末尾）：
“头部样本内部的轨迹差异提示，强队优势并不必然来自短期极值表现，而更可能来自风格状态的长期可复制性。长期稳定停留在高竞争质量类型的球队，通常具备更低的战略摩擦成本；相对地，频繁跨类型迁移的球队虽然可能在局部赛季获得战术红利，但也更容易在赛季间出现表现波动。该发现为‘稳定性是否构成竞争优势来源’提供了可量化的经验证据。”

## 2.5 本章小结

本章构建并验证了一个由12变量驱动的球队风格识别体系。通过因子分析提取3个潜在风格维度，在保留70.94%信息的前提下显著压缩变量空间；通过4类聚类实现球队风格分型；通过赛季演化分析揭示了联赛风格结构的动态迁移。整体结果表明，英超球队风格是多维、动态且可度量的，这为下一章开展“风格与竞争绩效关系”分析提供了方法基础与实证输入。
